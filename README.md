# TechPulse

TechPulse is a simple technology blog website. Users can read blog posts about technology, programming, and software development.

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- Cloudinary

## How to Run the Project

**Frontend**

```bash
cd client
npm install
npm run dev
```

**Backend**

```bash
cd server
npm install
npm run dev
```
